Mountain-ERP

Система автоматизации учета и управления бизнесом.

Функциональные возможности

  • • Полный цикл: складской учет, закупки, рабочее место кассира (POS).
  • • Модуль рассрочки: автоматизация сделок по принципам «Мурабаха».
  • • Аналитика: отчеты P&L, эффективность товаров, прогноз поступлений.
  • • Offline-first: локальное хранение базы данных без зависимости от серверов.

Технические детали

Стек: React + TypeScript + Electron. Локальное хранение данных.
